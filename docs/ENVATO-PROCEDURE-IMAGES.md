# Envato photo sourcing — official 2026 catalogue procedures

Every official catalogue treatment shows a card image at
`public/images/procedures/<slug>.jpg` (see `procedureMedia()` in
`src/lib/catalogue.ts`). The current files are AI-generated placeholders —
replace each with a **real photograph** from Envato Elements using the links
below. Overwrite the file at the listed path with the same name and the site
picks it up automatically (no code change needed).

## How to search (do this for every image)

1. Open the search link (it lands on **Photos** results only).
2. In the left sidebar, set the **“Generated with AI”** filter to **Excluded**
   (Envato exposes no URL parameter for this — it must be set by hand; items
   are also labelled “Generated with AI” on their cards, so double-check the
   item page before downloading).
3. Prefer: real clinical settings, natural light, no watermark-style overlays,
   landscape orientation ≥1600px wide.
4. License the photo under the clinic's Envato subscription, download, crop to
   roughly 4:3, save as JPG at the target path.

Base URL pattern: `https://elements.envato.com/photos/<search+terms>`

## Notes

- **Never** publish an image still labelled “Generated with AI” on its Envato
  item page — the whole point of this pass is real photography.
- Legacy (non-official) treatments keep their existing card images; only the
  official list above needs sourcing.
- If a search comes up empty after excluding AI, drop the most specific word
  first (e.g. “Estelite” → plain “composite filling”).
