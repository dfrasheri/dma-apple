# Design Tokens — The Paddington Dental Surgery

## Fonts
- **Serif / display:** `bodoni-moda-variable` (Adobe Typekit Bodoni Moda) → use Google Font **Bodoni Moda** as equivalent. Used for: hero title, all section H2s, card titles, blockquote, IG title.
- **Sans / body:** `roboto` → **Roboto**. Used for: body copy, nav links, buttons, eyebrows, form.

## Colors
| Token | Value | Use |
|---|---|---|
| navy (heading) | `#071522` rgb(7,21,34) | section headings |
| ink (body) | `#343434` rgb(52,52,52) | body text, scrolled nav text |
| white | `#ffffff` | page bg, hero/overlay text |
| nav-scrolled-bg | `#e6e6e6` rgb(230,230,230) | nav bar after scroll |
| button-bg | `#f1f1f1` rgb(241,241,241) | light buttons |
| overlay-scrim | rgba(0,0,0,.35–.5) | image overlays for white text |
| cta-bar | ~`#3a3a3a` dark gray | sticky bottom bar |

## Type scale (computed)
- Body: Roboto 17px / line-height 24px / weight 300 / letter-spacing -0.17px / color #343434
- Section H2: Bodoni Moda 40px / 46px / weight 400 / color #071522
- Hero title "Sydney's Home of Dentistry": Bodoni Moda ~60–64px / white
- Card title (Advanced Technology / Gentle Experience / Unveiling Beautiful Smiles): Bodoni Moda ~40–48px / white
- Blockquote: Bodoni Moda 23px / 28px / letter-spacing -0.6px / #343434
- Nav links: Roboto 22px / color #343434 (scrolled), #fff (over hero)
- Buttons: Roboto 20px / weight 400 / UPPERCASE / color #343434 / bg #f1f1f1 / padding 14px 30px / border .67px solid #f1f1f1 / radius 0
- Eyebrow (GENERAL | COSMETIC | RESTORATIVE, LIFE-CHANGING…, STATE-OF-THE-ART…): Roboto UPPERCASE, letter-spacing ~1.5px, white
